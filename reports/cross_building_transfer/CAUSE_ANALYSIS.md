# 为什么简化 Transfer GP 在 UJI 跨建筑失败？实测机制诊断

**数据日期**：2026-10-13；**修正后结果**：同日重新运行。
**性质**：公开 UJI 数据上的五次独立拆分诊断，不是 AAMAS 2020 TNKN 算法或其 RMSE 数值复现。

- 论文：[Wei et al., Adaptive Knowledge Transfer based on Transfer Neural Kernel Network, AAMAS 2020](https://www.ifaamas.org/Proceedings/aamas2020/pdfs/p1485.pdf)
- 主要实验：[实验代码](../../experiments/cross_building_transfer.py)、[汇总结果](aggregate.csv)、[逐次结果](results.json)
- 核诊断：[诊断代码](../../experiments/diagnose_transfer_rbf.py)、[逐次核指标](kernel_diagnostics.json)
- UJI 来源：UCI 官方 `trainingData.csv`，ZIP SHA256 `893512b82dfd7a7c345d84195b1c8019fbca0fa0d7820ce491ce5aa45ec3782f`。
- 每次源域随机 1000 **指纹样本**，目标域 K=25 **不同建筑—楼层—坐标的标定位置**、每位置一条扫描；目标未标定位置 Query 最多 1000 条扫描。五个拆分种子 `20261013…20261017`，官方后期 `validationData.csv` 不参与。
- RSS：UJI 520 维；`100` 未检测转换为 0，真实 RSS 映射为 `(RSS+110)/110`。源域子抽样估计单个 RBF 长度尺度，GP 噪声固定，输出坐标分别按源/目标 Support 均值去中心并除以固定常数 50。
- 只用同一个 RBF 核 `k`，跨域块 `rho*k`；`rho ∈ {0,.25,.5,.75,1}`，条件目标标定标签边缘似然选择。`rho=1` 不等价于论文原始 GPall 的无条件全域坐标合并。
- 单独诊断使用有符号网格 `{-1,-.75,-.5,-.25,0,.25,.5,.75,1}`，**仅诊断**，不会修改主实验。

## 复现目标本身不同

**作者 AAMAS 2020**：源 B1 1000 条、目标 B2 25 条训练 + 1000 条测试；两个 RBF + 一个线性基础核，线性层 3→4、乘积 4→2、线性层 2→1，源目标共享/跨域分开核组合系数，Adam 0.001、5000 epochs，并**联合优化**基础核超参数、组合系数及两域观测噪声。论文问题定义为单输出 `y ∈ R`，其 0.0963 是报告的标量 RMSE 口径，并非能够直接换算为二维平面定位 MDE。UJI 的采样索引、输出分量/归一化细节未充分提供；没有核实到可直接运行 UJI 的官方仓库。

**本项目 pilot**：原始 520 维归一化 RSS 的单 RBF + 单标量 rho、未联合优化核或噪声、二维坐标 GP、真实独立参考位置划分。因此只能检验一个受限核族，不可称为 TNKN 复现失败。

## 修复过的划分问题（结果已经重新生成）

旧实验使用 `pos=(round(x,.1),round(y,.1))` 表示一个标定位置，**没有包含 FLOOR**；B2 全建筑共有 84 个平面坐标组跨多个楼层。原来所谓“不同参考位置”其实只是不同水平坐标，未严格保证不同物理楼层位置。

现已改为 `pos=(building,floor,round(x,.1),round(y,.1))`。源/目标、Support/Query 均依正确 RP 身份划分，所有表格已重跑。**以前的 B1→B2 20.07 m 不再是有效的最新主数字**。

## 结果：五次独立拆分平均 MDE

|任务|目标 GP (rho=0)|简化迁移 GP 自动选 rho|目标 wKNN|
|---|---:|---:|---:|
|B1→B2，K25|**21.97**|22.88|23.43|
|B0→B1，K25|**22.62**|22.94|23.75|
|B0→B2，K25|22.10|**21.96**|23.43|
|B1 其他楼层→B1F3，K5|34.89|**24.29**|39.55|
|B1 其他楼层→B1F3，K10|25.34|**20.24**|30.86|

**跨建筑结果**：B1→B2 不但没有平均改善，五次目标证据选到的 rho 分别是 `[0,1,0,0,0]`；第二次选 `rho=1`，但目标仅用 GP 22.99，迁移后 27.55。其他大多无法检测到有益迁移。B0→B2 平均只改善 0.14，不能视为稳健跨建筑收益。

**验证是否仅仅漏掉负相关**：允许 `rho∈[-1,1]`（9 个值）后，B1→B2 五次都选负 rho，但平均 MDE **22.82**，仍差于 21.97 的目标 GP。即使非法地用 Query 标签作每次 oracle 选 rho，平均也只到 **21.77**。所以不是“忘了允许 rho<0”就能解决。

## 关键机制：核相似性存在，但它和空间坐标关联不正确

对五次拆分，独立计算未经修正的**源数据 GP 初步预测**，并利用 K 条目标标签均值提供相同的平移原点。不使用目标 GP 残差修正时：

|诊断|B1→B2 K25|B1 其他层→B1F3 K5/10|
|---|---:|---:|
|跨域 RBF 核中位数|0.520|0.659|
|源 GP 在目标 Query 上 MDE|**45.10**|**31.59**|
|仅预测目标 K 个坐标均值的 Query MDE|**41.10**|**55.65**|

注意，跨建筑核 `~0.52` 并非趋近 0，说明“跨域核没有覆盖，因而源信息进不来”的单一解释不成立。尽管核非零，**通过源任务的 RSS→坐标函数传播出来的目标空间偏移并不可靠**。

一个强佐证是 B0→B2：本次源域抽样及目标 Support 平均只有 ~2–3 个共同可检测 AP，**跨域 RBF 核中位数仍然 ~0.52**。因为稀疏 RSS 中大量 AP 值被补成 0，欧氏距离与 RBF 相似性可能反映共同缺失结构以及信号稀疏程度，不能单独保证迁移到正确的物理位置关系。这说明**在这种核下，非零相似性 ≠ 准确跨空间对应**。

对照 B1 其他层→B1F3，源 GP 已经能比目标标定中心显著更准确地估计位置偏移，因此即使只有 K5/K10 个新位置，源坐标关系也更可能成为正迁移。

这是机制一致的证据，但不构成对“共同缺失是唯一原因”的因果证明。要区分它与不同建筑几何/坐标变换、设备、AP 词表等因素，仍需额外专门消融。

## 对 TNKN 路线的判断

1. **目前失败的直接可证原因**：不是原文 TNKN 不成立，而是原文实际优化的复合核没有实现；我们测试的是固定单 RBF + 标量 rho，跨域预测关系在 B1→B2 上不可靠。
2. **原论文方法是否可能修复**：两个尺度 RBF、线性核、乘积组合、同域/跨域不同权重、参数与噪声联合训练，可能改变源目标坐标关系；但尚未被实验验证在严格 K25 **不同物理位置**、二维坐标指标下有效。
3. **从物理意义的路线限制**：TNKN 默认源目标的特征空间维度与每一维含义对应，所学的是统计核结构，而非新建筑 AP 安装位置或墙体几何。不同 AP 网络中即使强行对齐列，也缺乏有用的空间对应关系，核结构无法凭空消除不可辨识性。
4. **现有证据不能支持的判断**：不能据 2020 年归一化标量 RMSE=0.0963 宣称“新建筑仅需 25 个独立标定位置即可定位到 0.0963 米”，也不能据本实验否定 TNKN 论文结果。作者的五次 restart 是初始化重复，不能替代跨楼/跨建筑源目标对的泛化试验。
5. **若继续忠实复现，最低必要条件**：先重现 GPtar/GPall 同口径标量回归与 preprocessing，再建立两 RBF+线性基础核的有效 PSD 组合、联合学习噪声和核参数；最后将结果移到独立 RP、二维米制任务。只有这样，才能判断 TNKN 的结构是否填补了单 RBF 失败的缺口。

实际最明确的发现是：**环境间的 RSS 核相似性与环境间的 RSS→位置函数可迁移性并非一回事**，而 GP 的目标概率证据不一定能选出最低定位误差的迁移强度。两项结论均有 pilot 诊断支撑，但仍需控制坐标处理及完整 TNKN 方可判定一般性。
